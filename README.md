# ETW (Excel To Word)

Excel转Word命令行工具，支持新增、追加和覆盖三种工作模式。

## 版本

当前版本：1.1

## 安装

### Python环境运行
1. 确保已安装 Python 3.10 或更高版本
2. 安装依赖：
```bash
pip install -r requirements.txt
```
3. 运行：
```bash
python etw.py -i input.xlsx -o output.docx
```

### EXE程序运行
直接运行 `etw1.1.exe`（无需安装Python）：
```bash
etw1.1.exe -i input.xlsx -o output.docx
```

## 使用方法

### 基本语法
```
etw.py [-h] -i I -o O [-F] [--CK1 CK1] [--CK2 CK2] ... [--HM1 HM1] [--HM2 HM2] ...
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `-i` | 输入Excel文件路径（必填） |
| `-o` | 输出Word文件路径（必填） |
| `-F` | 强制覆盖模式：未匹配的Excel行不新增表格 |
| `--CK1` ~ `--CK4` | 根字段参数，用于匹配（最多4个，AND关系） |
| `--HM1` ~ `--HM20` | 覆盖字段参数，指定需要覆盖的列名（最多20个） |

### 工作模式

工具根据输出文件状态自动选择工作模式：

| 输出文件状态 | 参数条件 | 工作模式 | 说明 |
|-------------|---------|---------|------|
| 不存在 | 任意 | **新增模式** | 创建新文档，每个Excel行一个带标题的表格 |
| 存在 | 无CK参数 | **追加模式** | 在原文档末尾追加新的表格 |
| 存在 | 有CK参数 | **覆盖模式** | 根据CK匹配更新已有表格的值，未匹配则新增 |

### 使用示例

#### 示例1：首次转换
```bash
etw1.1.exe -i source.xlsx -o dest.docx
```
创建新Word文档，每个Excel行生成一个带4级标题的表格。

#### 示例2：追加数据
```bash
etw1.1.exe -i source2.xlsx -o dest.docx
```
在原文档末尾追加新的表格。

#### 示例3：覆盖模式
```bash
etw1.1.exe -i source.xlsx -o dest.docx --CK1 用例编号
```
根据"用例编号"匹配Word中的表格，更新匹配表格的值。

#### 示例4：强制覆盖 + 指定字段
```bash
etw1.1.exe -i source.xlsx -o dest.docx -F --CK1 用例编号 --HM1 整改措施 --HM2 回归结果
```
只更新匹配的表格，未匹配的行不新增。指定只覆盖"整改措施"和"回归结果"两个字段。

## 表格结构

生成的Word文档包含以下结构：
- **文档标题**：Excel数据转换结果
- **表格标题**：4级标题，格式为 `{用例编号}:{用例标题}`
- **表格内容**：2列表格（字段名 | 值）

### 预定义字段顺序
```
试验标识 → 用例编号 → 用例标题 → 问题等级 → 问题标题 → 问题描述 → 
原因分析 → 整改措施 → 整改方 → 回归步骤 → 回归人员 → 问题单编号 → 
问题单类型 → 整改方联系人 → 回归单编号 → 回归单类型
```
